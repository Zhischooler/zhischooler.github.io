

# 步骤

1. 打开 Microsoft Store。

   - 点击任务栏的“开始”按钮。
   
   - 在搜索框输入 Microsoft Store。
   
   - 点击打开。
   
   - 或者直接点击任务栏上的 Microsoft Store 图标。
   
2. 搜索 Windows Terminal。

   - 在 Microsoft Store 顶部的搜索框输入 Windows Terminal。

   - 下方的推荐结果中点击 `Windows Terminal`

   
3. 选择应用。

   - 在搜索结果中找到 Windows Terminal。
   
   - 确认发布者是 Microsoft Corporation。
   
   - 点击进入详情页。
   
4. 下载安装。

   - 点击“获取”或“安装”。
   
   - 等待下载和安装完成。
   
5. 打开 Windows Terminal。

   - 安装完成后，按钮会变成“打开”，点击“打开”。
   
 **进入命令行（快捷）**
 直接`Win+R`，输入cmd
   


7. 以后使用。

   - 点击“开始”按钮。
   
   - 搜索 Windows Terminal。
   
   - 点击打开。
   
   - 再选择“命令提示符”。
   
8. 固定到任务栏（可选）。
   - 打开 Windows Terminal 后，右键任务栏中的图标。
   
   - 选择“固定到任务栏”。
   
   - 以后直接从任务栏打开。
