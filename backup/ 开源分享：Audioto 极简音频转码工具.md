分享我开源的基于 PySide6 的极简桌面端音频转码工具 Audioto。

## 核心功能

- 支持 MP3, WAV, FLAC, AAC, OGG 互转

- 自定义输出目录与码率

- 实时进度显示
 
- 界面简洁

## 使用方式

### 方式一：直接运行
下载打包好的 `.exe` 文件（内置 ffmpeg），双击即可运行。

### 方式二：源码运行
1. 安装 Python 3.8+

2. `pip install PySide6`

4. 将 `ffmpeg.exe` 放在同级目录

5. 运行主程序
